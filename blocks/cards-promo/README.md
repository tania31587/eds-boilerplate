# cards-promo

Custom **cards** block. Promo tiles: full-width photo above a dark plum panel with a taupe serif title, white description and a red button, two per row.

## Authoring (Document Authoring)

Model: `standalone`

| Cards Promo | |
| --- | --- |
| picture | title (H3 or bold paragraph), description paragraph(s), button link in its own paragraph |
| (one row per card) | |

Cells may be merged or split: the picture is found anywhere in the row, the last paragraph holding only a link becomes the button, and the first remaining element is the title. Empty cells are ignored.

## Supported variations

No variations.
