# cards-quote

Custom **cards** block. Persona cards on a beige panel: circular portrait, serif quotation, description and an arrow "Learn more" link, two per row.

## Authoring (Document Authoring)

Model: `standalone`

| Cards Quote | |
| --- | --- |
| portrait picture | quotation paragraph, description paragraph(s), link in its own paragraph |
| (one row per card) | |

Cells may be merged or split: the picture is found anywhere in the row, the last paragraph holding only a link becomes the arrow link, and the first remaining element is the quotation. Author the quotation as a paragraph, not a heading. Empty cells are ignored.

## Supported variations

No variations.
