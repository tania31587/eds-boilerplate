# hero-split

Custom **hero** block. Page-top title hero: beige text panel on the left, photo flush right (photo hidden at 975px and below).

## Authoring (Document Authoring)

Model: `standalone`

| Hero Split |
| --- |
| picture (photo shown on the right) |
| H1 title, optional subheading paragraph, optional link |

Rows and cells may be merged or split: the picture is found anywhere in the block and every other element goes to the text panel in authored order. Empty cells are ignored; with no picture the text panel fills the width.

## Supported variations

No variations.
